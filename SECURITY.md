# Security policy

## Supported versions

Security fixes are applied to the latest released version. Users should update the extension and self-hosted bridge promptly.

## Reporting a vulnerability

Do not open a public issue. Use GitHub's private vulnerability reporting for this repository. If that feature is unavailable, contact the maintainers through the private address listed on the repository owner's GitHub profile and include “Panodash security” in the subject.

Include the affected version, impact, reproduction steps, and any suggested mitigation. Do not include real user tokens or metric exports. Maintainers will acknowledge a report as soon as practical, validate it privately, coordinate a fix and disclosure, and credit reporters who want attribution.

## Scope

Reports involving credential exposure, origin-permission bypass, unsafe import or sharing, OAuth state/session handling, bridge token storage, or extension content injection are especially valuable. Provider outages and vulnerabilities exclusively in third-party services should be reported to those providers.
