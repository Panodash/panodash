# Panodash brand and launch kit

**Big idea:** See your whole signal.

This directory is the source of truth for the Panodash identity and launch. Start with the [visual brand board](index.html), then use the two working documents:

- [Brand system](brand-system.md) — positioning, identity rules, voice, color, typography, and product expression.
- [Launch campaign](launch-campaign.md) — narrative, channel plan, exact copy, rollout, asset checklist, and measurement.
