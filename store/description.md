# Chrome Web Store description

## Short description

A private, local-first dashboard for the metrics you care about—on every new tab.

## Full description

Panodash turns every new tab into a calm, vivid view of your personal signals. Bring health, activity, finance, weather, and custom API metrics together without handing a consolidated profile to another dashboard service.

Highlights:

- Arrange a flexible dashboard of focused metric tiles.
- Review recent history and trends without leaving the new tab.
- Connect built-in providers—including matching GitHub and GitLab review, PR/MR velocity, cycle-time, milestone, branch, CI, issue-triage, release, contributor, and notification/to-do signals—or a custom JSON endpoint.
- Choose light, dark, and customizable brand palettes.
- Export your dashboard and share sanitized configurations.
- Keep dashboard data and history in local extension storage.

Panodash requests network access only for widgets you configure. Some OAuth providers can use the optional open-source bridge; metric data still flows directly from the provider to your browser.

Panodash is open source. Review the code, self-host the optional OAuth bridge, and build providers against the widget SDK.
